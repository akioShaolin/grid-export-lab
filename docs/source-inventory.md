## Classificação por família

| Família | Linguagem/tipo | Papel rede/Modbus | Situação e sensibilidade original |
|---|---|---|---|
| Túnel | C++/Arduino | cliente/servidor TCP, transporte RTU | histórico; Wi-Fi, senhas, IPs fixos |
| Gateways URP | C++/Arduino | mestre RTU, servidor Modbus TCP | histórico; v5 experimental; credenciais/rede |
| Loggers/host | Python | cliente Modbus TCP; host também cliente de comandos | histórico; endereços operacionais |
| Gateway inversor | C++/Arduino | servidor TCP, mestre RTU | histórico; Wi-Fi e hostname |
| Edge | C++/Arduino, headers | cliente TCP, mestre RTU, servidor HTTP | experimental, identidade/credenciais/defaults |
| Coletores/painéis | Python, HTML, batch | cliente HTTP ESP, servidor HTTP histórico | manter pares locais; nomes e hostnames identificavam instalação |
| Notas/patches | Markdown/diff | documentação, fragmento externo não aplicado | histórico; README repetido exige leitura crítica |
| CSVs | dados de campo | saídas runtime | excluídos por privacidade |
| Binários/checksums | artefatos gerados | nenhum fonte executável editável | excluídos |
| Imagens/sk1 | raster e diagrama externo | documentação | fora do repo, sanitização não comprovada |
| Manuais | PDF/pacote externo | referência de fabricantes | fora do repo, sem licença de redistribuição confirmada |

Datas de autoria não comprovadas, exceto referências bibliográficas declaradas. A classificação e os destinos se baseiam no conteúdo, nos includes, nos mapas e nas mensagens, não apenas na numeração dos arquivos.
